# GeoRAG
An assistant that answers questions about geological documents with varying formats and non-standardized text.

## Dataset
- Dataset of synthetic geological information featuring diverse formats and non-standardized text.

## Technologies Used
### Language
- Python

### Generative AI
- Hugging Face – Inference API

### RAG Used
- LangChain
- ChromaDB
- Setence Transformers

## Quick Start 
- First, run ingest.py to index the documents into the vector database. 
- Then, run chat.py to interact with the GeoRAG assistant.
