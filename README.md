# GeoRAG
Um assistente que responde perguntas sobre documentos geológicos que possuem formatos diferentes e textos não padronizados.

## Dataset
- Dataset of synthetic geological information featuring diverse formats and non-standardized text.

## Technologies Used
### Language
- Python

### Generative AI
- Hugging Face – Inference API

### RAG Used
- LangChain
- ChromaDB
- Setence Transformers
